# Якоря эмоциональных состояний — PDF к встрече

- `index.html` — 4 слайда 16:9 (1600×900), стиль отчётов neurocentre.
- `yakorya_investor.pdf` — собранный PDF; на слайде 4 превью отчёта целиком является ссылкой, рядом QR-код.
- `maket.md` — текстовый макет по слоям («Ясно»).
- `img/bruegel_winter.jpg` — картина для слайда 2 (скачивает `get_bruegel.py`; можно заменить фото из галереи под тем же именем).
- `shots/01_hero.png` — первый экран отчёта для слайда 4 (снимает `build_local.cmd`; можно заменить своим скриншотом).

Сборка на Windows: `build_local.cmd` (Edge headless).
Сборка в Linux: `NODE_PATH=$(npm root -g) node build_pdf.js --png`.
Пока файлов картинок нет, на их местах стоят аккуратные заглушки.
